## Source and status

The published IPTrust brand record currently has no primary design guide or published design-token file. The design guide in this repository applies the published brand positioning, palette, and classifications; derived interface guidance and color variants are identified in the files. Published values and provenance are kept in `data/`.

## Initial snapshot

Brand files and published records were seeded from [ksamint/tableai_designaha](https://github.com/ksamint/tableai_designaha/tree/17e8486df5cc2896049164fdef9c876e5790897b/IPTRUST) at `17e8486df5cc2896049164fdef9c876e5790897b` and the published brand API. Existing tracked brand files retain their original paths.

Official media remains at the URLs in `data/assets.json`; checksums identify the exact assets. Only files already tracked in the source repository were copied. Local ignored and private files were not imported.

This repository can evolve independently; changes here do not automatically synchronize back to the catalog. Consult [apuch.art](https://apuch.art/) and its brand API for the latest published brand guidance.
